# Hello World 你好世界

欢迎来到我的博客！Welcome to my blog!

这是一个使用 **Astro** 和 **shadcn/ui** 构建的现代博客框架，支持中英文混排。

## Features 功能特点

- 🌓 暗色模式支持 Dark mode support
- 📱 响应式设计 Responsive design
- 🏷️ 标签系统 Tag system
- 📅 文章时间线 Article timeline
- 🔗 友情链接 Friend links
- 📡 RSS 订阅 RSS subscription
- 🔍 SEO 优化 SEO optimization

### 暗色模式 Dark Mode

支持跟随系统或手动切换的暗色模式。

### 响应式设计 Responsive Design
